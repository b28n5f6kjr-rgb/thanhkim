# Public showcase — Biên tập tin đa phương tiện

Website tĩnh giới thiệu Hermes Agent `media-news-editor`.

## Bảo đảm của bản showcase

- Không có backend, form tải file, webhook, analytics hoặc lời gọi API.
- Demo trong `demo.js` là nội dung giả lập viết sẵn, không gửi dữ liệu đi đâu.
- Không chứa Hermes `SOUL.md`, cấu hình, credential, session hoặc tài liệu nguồn nội bộ.
- Trạng thái hiện tại nói rõ rằng chưa có phiên âm/ghi Feishu đầu-cuối được xác minh.

## Chạy thử cục bộ

Mở `index.html` trực tiếp trong trình duyệt. Trang chỉ dùng các tệp tĩnh trong thư mục này.

## Xuất bản

Có thể xuất bản thư mục này làm website tĩnh bằng GitHub Pages. Chỉ đưa các tệp trong `public-showcase/` vào repo công khai; không đẩy thư mục dự án Agent hoặc Hermes Profile.
